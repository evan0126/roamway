## 学习笔记

### 1. 独立输出模型

`backend/models.py`：

```python
class TripOutput(TripInput):
    id: int = Field(gt=0)
```

继承 TripInput 的字段和校验，新增必填编号。模型负责校验，不自动生成编号或保存数据；服务端在创建接口中生成编号。

### 2. 模型练习

练习文件为 `backend/response_model_basics.py`，在项目根目录执行：

```bash
backend/.venv/bin/python backend/response_model_basics.py
```

| 场景 | 实际结果 |
| --- | --- |
| 完整行程和 id=1 | 正常创建，model_dump() 包含编号及行程字段 |
| id=0 | ValidationError，要求大于 0 |
| 缺少 id | ValidationError，提示字段必填 |
| 修改导出的字典 | 原对象的 id 仍为 1 |
