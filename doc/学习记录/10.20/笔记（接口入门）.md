## 4. 健康检查接口

计划在 `backend/api.py` 编写：

```python
from fastapi import FastAPI

app = FastAPI()


@app.get("/health")
def health() -> dict:
    return {"status": "ok"}
```

`app = FastAPI()` 创建应用实例。`@app.get("/health")` 是装饰器写法，将下面的函数注册为 `GET /health` 的处理函数。注册时不直接执行函数体；收到匹配请求后，框架调用函数并将返回的字典转换为 JSON 响应。

本例先用普通 `def` 实现简单响应，异步函数与阻塞操作的边界在后续课程学习。

## 5. 启动与模块入口

在 `backend` 目录、已激活虚拟环境的终端中执行：

```bash
python -m uvicorn api:app --reload
```

- `api`：加载当前目录的 `api.py` 模块。
- `app`：使用该模块导出的应用对象。
- `--reload`：开发时监听代码变化并重启服务。

服务持续占用当前终端，按 Ctrl+C 停止。与之前运行一次即退出的练习脚本不同，此时服务持续等待请求。
