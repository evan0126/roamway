## 学习笔记

### 1. 列表与详情接口

`backend/api.py`：

```python
@app.get("/trips", response_model=list[TripOutput])
def list_trips() -> list[TripOutput]:
    return list(trips.values())

@app.get("/trips/{trip_id}", response_model=TripOutput)
def get_trip(trip_id: int) -> TripOutput:
    trip = trips.get(trip_id)
    if trip is None:
        raise HTTPException(status_code=404, detail="行程不存在")
    return trip
```

`trips.values()` 取出字典里的行程对象，转成列表返回。空集合返回 `[]`，是正常结果；详情找不到指定编号则返回 404。`trip_id` 来自 URL 路径，不是请求体。

### 2. 列表有数据但详情查不到

用户反馈编号 1、2 查不到，但文档页面上仍有列表。助手实际执行：

```bash
curl --silent --show-error -i http://127.0.0.1:8000/trips
curl --silent --show-error -i http://127.0.0.1:8000/trips/1
curl --silent --show-error -i http://127.0.0.1:8000/trips/2
```

当时列表为 `200 []`，两次详情均为 `404 {"detail":"行程不存在"}`，当前代码查询逻辑正常。结合新增代码触发热重载，页面很可能显示上一次的响应；重新 Execute 才是当前结果。服务重启后需重新创建，再按新编号查询。
