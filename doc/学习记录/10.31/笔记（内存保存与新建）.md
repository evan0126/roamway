## 学习笔记

### 1. 当前创建流程

`backend/api.py` 的 `POST /trips` **无需请求体**，默认成功状态码为 200；从 `backend/mock_data.py` 的 `trip_samples` 随机选一条，允许重复，每次分配新编号。

```python
trips: dict[int, TripOutput] = {}
next_trip_id = 1

@app.post("/trips", response_model=TripOutput)
def create_trip() -> TripOutput:
    global next_trip_id
    trip = TripInput(**random.choice(trip_samples))
    saved_trip = TripOutput(id=next_trip_id, **trip.model_dump())
    trips[saved_trip.id] = saved_trip
    next_trip_id += 1
    return saved_trip
```

代码节选，导入见源文件。字典以编号为键、输出对象为值。输入模型校验通过后才写入内存，编号由服务端分配。`global` 与字典展开见[后端语法基础](../10.18/笔记（后端语法基础）.md)。

mock 覆盖 1～5 天、零预算、小数预算、亲子、摄影、徒步等主题；金额仅为模拟值，不是旅行报价。创建接口不会读取客户端提交的行程内容，当前不要用它验证客户端非法字段的 422 响应。

### 2. 内存和热重载

在 backend 目录启动：

```bash
.venv/bin/python -m uvicorn api:app --reload --host 127.0.0.1 --port 8000
```

- 刷新浏览器不会清空后端内存。
- 保存 Python 文件触发热重载，会重新加载代码及 mock，清空 trips，编号回到 1。
- 修改 mock 不会自动创建记录，需再次调用 POST。
- 已打开的 `/docs` 页面不会自动刷新；旧响应可能仍显示重启前的数据，需要重新 Execute。
- 内存属于单个进程，不是数据库持久化；当前练习未覆盖并发或多进程编号安全。
